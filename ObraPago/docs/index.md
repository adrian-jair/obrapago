# ObraPago

**Sistema Ágil de Control de Jornales, Asistencia y Pagos para Constructora.**

En la Unidad 1 de Lenguaje de Programación 2, el backend se implementa como un **monolito modular Spring Boot** conectado a Oracle.

Módulos funcionales en este corte:

- **Obreros**: padrón y CRUD maestro.
- **Asistencia**: registro transaccional cabecera-detalle.

Módulos previstos para etapas posteriores:

- Adelantos
- Pagos
- Mensajes
- Respaldo
